🚀 HOW TO RUN THE WEBSITE:

1. START XAMPP
   - Open XAMPP Control Panel
   - Click "Start" for Apache

2. OPEN IN BROWSER
   - Go to: http://localhost/alumni/
   - Or: http://127.0.0.1/alumni/

3. EXPLORE THE WEBSITE
   ✓ Homepage with all sections
   ✓ Sidebar navigation (all links working)
   ✓ Responsive design (try resizing browser)
   ✓ Mobile menu (toggle button appears on small screens)

🗺️ MAPBOX SETUP (OPTIONAL):

The homepage has an interactive world map section.

To enable it:
1. Visit: https://www.mapbox.com/
2. Sign up (free)
3. Copy your access token
4. Open: assets/js/script.js
5. Replace: mapboxgl.accessToken = 'YOUR_TOKEN_HERE';

Without token: Shows fallback message (still looks good!)
